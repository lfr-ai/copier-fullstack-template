# UI/UX Frontend Rules

- Prefer semantic HTML and role-first accessibility.
- Ensure keyboard navigation and visible focus states are preserved.
- Model loading/empty/error/success states explicitly in UI flows.
- Keep forms accessible with labels, helper text, and contextual errors.
- Favor Storybook stories with representative user flows and interaction checks.
