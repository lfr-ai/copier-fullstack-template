# Agent Prompting Conventions

- Keep responses concise and actionable.
- Use English for code, comments, and technical documentation unless explicitly
  required otherwise.
- Verify architecture boundaries before edits.

## Code quality defaults

- No `any`.
- Named exports only.
- Internal constants are underscore-prefixed.
- Keep naming consistent across files, symbols, and tests.
